# 🏺 Sahand_Patturn

این مخزن شامل **تحلیل کامل محصول Patturn Studio** (ابزار طراحی پارامتریک برای سفالگران)،
**نقشه راه فازبندی‌شده** برای بازسازی آن، و **بستهٔ پرامپت چندفایلی** برای سپردن پیاده‌سازی به هوش مصنوعی است.

## 📂 مسیر بسته

➡️ **[`patturn-rebuild/`](./patturn-rebuild)**

| فایل | محتوا |
|------|-------|
| [`README.md`](./patturn-rebuild/README.md) | جلد، فهرست و راهنمای استفاده از بسته |
| [`index.html`](./patturn-rebuild/index.html) | نسخهٔ خواندنی یکجا (RTL، با فهرست کنار صفحه و نمودارها) |
| `00` تا `13` | تحلیل سایت، نقشه راه، پرامپت اصلی، معماری، مدل داده، ماژول‌ها، طراحی، بک‌اند، تست و تحلیل شکاف |

## ⚡ شروع سریع

1. `patturn-rebuild/index.html` را باز کنید تا کل ماجرا را ببینید.
2. برای دادن به هوش مصنوعی: `02-MASTER-PROMPT.md` را کپی کنید و فایل‌های `03` تا `11` را ضمیمه کنید.
3. برای کیفیت بالاتر: ابتدا `01-ROADMAP.md` و سپس پرامپت‌های `12-PHASE-PROMPTS.md` را فاز به فاز بفرستید.

## 🛠️ بازسازی نسخهٔ HTML

پس از هر ویرایش مارک‌داون‌ها:

```bash
python3 patturn-rebuild/build_handbook.py
```
