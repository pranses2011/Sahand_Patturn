## 1️⃣ 🍪 کاتر کوکی (Cookie Cutter)

### ریاضیات
```
کانتور (بسته، بدون خودتقاطع)
 → آفست بیرونی = ضخامت تیغه (0.8–1.5mm)
 → extrude عمودی = bladeHeight (ضخامت اسلب + 2mm)
 → شیار تیغه (taper): لبهٔ بالایی ضخیم‌تر، لبهٔ پایینی نازک (sharpness)
 → دستهٔ بالا (rib) برای نگه‌داشتن شکل
```

### پارامترها
| پارامتر | پیش‌فرض | بازه |
|---------|---------|------|
| `bladeHeightMm` | 25 | 10–60 |
| `bladeThicknessMm` | 1.0 | 0.4–2.5 |
| `sharpnessDeg` | 15 | 5–35 |
| `handleEnabled` | true | — |
| `handleThicknessMm` | 2.5 | 1–5 |
| `rimWidthMm` | 4 | 0–10 |

### فرمول‌های اعتبارسنجی
```
بلید باید از اسلب کامل رد شود:  bladeHeight ≥ slabThickness + 2mm
تیغه نباید بشکند:  thickness / height ≥ 0.03
شعاع داخلی حداقل:  r ≥ thickness  (وگرنه تیغه خودتقاطع می‌شود)
```

### ورودی‌ها
| ورودی | توضیح |
|-------|-------|
| 📥 SVG | دراپ فایل → مسیرها |
| ✏️ ترسیم آزاد | همان ویرایشگر وکتور داخلی |
| 🖼️ ترسیم تصویر | آپلود → ترِیس خودکار |
| 🔤 متن | تبدیل متن به مسیر (پشتیبانی فارسی) |

| مرحله | تنظیمات کاربر |

## 4️⃣ 🫖 دسته‌ساز (Handle Maker)

### مفهوم: Sweep پروفیل روی مسیر
```
مسیر (Path3D): منحنی Bézier سه‌بعدی که از بدنه بیرون می‌آید و برمی‌گردد
مقطع (Cross-section): دایره / بیضی / مستطیل گرد / پروفیل دلخواه
sweep: در هر نمونه از مسیر، مقطع را در صفحهٔ نرمال قرار بده
Frames: از «موازی انتقال» (parallel transport) برای جلوگیری از پیچش استفاده کن
```

### پارامترها
| پارامتر | پیش‌فرض | توضیح |
|---------|---------|-------|
| `attachTopY` | 70% ارتفاع | نقطهٔ اتصال بالا |
| `attachBottomY` | 30% | نقطهٔ اتصال پایین |
| `outwardMm` | 45 | فاصلهٔ بیرون‌آمدگی |
| `widthMm` | 22 | عرض مقطع |
| `thicknessMm` | 12 | ضخامت مقطع |
| `shape` | `oval` | oval / round / flat / custom |
| `pullOut` | 8 | دندانهٔ بیرون‌زدگی |

### قواعد ساخت
```
اتصال به بدنه باید «فیلت» شود (نه لبهٔ تیز) → union با blend radius ≥ 4mm
حداقل ضخامت دسته: 8mm (برای تحمل)
فاصلهٔ دسته از بدنه: ≥ 25mm (جا برای انگشتان)
حداکثر زاویهٔ twist: 5°
```

### قالب دسته
- ساخت قالب ۲تکه برای دسته (drop-out با محور عمودی)
- همان موتور فایل `07-MODULE-MOLDS.md` با ورودی «فرم غیرمحوری» → sweep-based → نیاز به parting plane
- خروجی: ۲ قطعه + کلیدها + محاسبهٔ گچ

## 5️⃣ 📐 ریب‌ساز (Rib Maker)

### مفهوم
ریب = ابزاری برای شکل‌دادن به سطح بیرونی فرم در حین چرخ‌کاری. هر ریب، **نگاتیو** انحنای مورد نظر است.

```
ورودی: پروفیل فرم (r(y)) یا پروفیل دلخواه
ریب = نوار با ضخامت t که لبهٔ آن همان منحنی است
پیش‌نمایش: revolve پروفیل + ریب → نشان بده چه فرمی می‌سازد
```

### پارامترها
| پارامتر | پیش‌فرض |
|---------|---------|
| `ribThicknessMm` | 3 |
| `ribHeightMm` | 40 |
| `edgeProfile` | `rounded` / `flat` / `beveled` |
| `handleLengthMm` | 80 |
| `flipForInside` | false (ریب داخلی/بیرونی) |

### خروجی
- SVG/DXF برای **برش لیزری** (پرکاربردترین)
- STL برای **پرینت سه‌بعدی**
- PDF ۱:۱ برای چاپ و برش دستی

## 6️⃣ 🔖 مهرساز (Stamp Maker)

### مفهوم
```
طرح (متنی/تصویری) → آینه‌سازی افقی (چون مهر معکوس است)
→ extrude با ارتفاع embossDepth (1.5–3mm)
→ پایه/دستهٔ پشتیبان (lens یا handle)
→ خروجی STL برای پرینت
```

### پارامترها
| پارامتر | پیش‌فرض | توضیح |
|---------|---------|-------|
| `stampType` | `signature` | signature / texture / pattern |
| `sizeMm` | 20 | عرض |
| `embossDepthMm` | 2 | برجستگی |
| `baseThicknessMm` | 3 | ضخامت پایه |
| `handleEnabled` | true | دستهٔ چاپی |
| `mirror` | true | آینه (برای مهر) |
| `textureBase` | `none` | dot-grid, herringbone… (از موتور الگو) |

> 💡 بافت‌های مهر از همان `packages/patterns` می‌آیند — ترکیب قابلیت‌ها (Lego).

### قواعد
```
حداقل عرض خط برجسته: 0.6mm (FDM) / 0.3mm (SLA)
عمق: 1.5–3mm
زاویهٔ دیواره: 5–10° برای خروج از قالب سیلیکون
```

## 7️⃣ 🔩 چاک‌ساز (Chuck Maker)

### مفهوم
چاک = نگه‌دارندهٔ فرم برای تریم وارونه. باید **معکوس** شکل دهانهٔ فرم باشد.

```
ورودی: فرم (سطح بیرونی در ناحیهٔ دهانه)
چاک = revolve(پروفیل معکوس بیرونی + tolerance 0.5mm) + پایهٔ استوانه‌ای
```

| پارامتر | پیش‌فرض |
|---------|---------|
| `chuckDepthMm` | 40 (چقدر از فرم را بگیرد) |
| `clearanceMm` | 0.5 |
| `baseDiameterMm` | خودکار (۱.۲× دهانه) |
| `wallMm` | 8 |
| `drainHoles` | true (سوراخ تخلیهٔ آب) |

> ⚠️ چاک باید **بدون گیر کردن** باشد: شیب ۲° به سمت بالا.

## 8️⃣ ⭕ رینگ‌روندر (Rim Rounder)

### مفهوم
پلاگ مخروطی که داخل دهانهٔ فرم قرار می‌گیرد تا در حین خشک‌شدن دهانه گرد بماند.

```
ورودی: قطر داخلی دهانه (D) یا فرم
پلاگ = مخروط ناقص با:
  r_top    = D/2 − clearance
  r_bottom = D/2 − clearance − depth·tan(taper)
  taper    = 3° (برای خروج آسان)
  handle   = استوانهٔ کوچک در بالا
```

| پارامتر | پیش‌فرض |
|---------|---------|
| `rimDiameterMm` | — (از فرم) |
| `depthMm` | 25 |
| `clearanceMm` | 0.4 |
| `taperDeg` | 3 |
| `wallMm` | 3 (توخالی برای صرفه‌جویی) |

## 🔟 📦 فرم Loft و Sweep (Extruded & lofted forms)

### Sweep
```
پروفیل (2D) در طول یک مسیر (3D) حرکت می‌کند
parallel transport frames → بدون پیچش
نتیجه: فرم‌های کشیده، دسته، لوله، اسلب خمیده
```

### Loft
```
دو یا سه پروفیل در ارتفاع‌های مختلف → درون‌یابی سطح بین آن‌ها
کاربرد: فرم‌های بیضوی، مربعی با دیوارهٔ گرد، فرم‌های قرینه‌نشده
```

| پارامتر | پیش‌فرض |
|---------|---------|
| `sections` | 3 |
| `interpolation` | `smooth` / `linear` |
| `closeCaps` | true |
| `twistDeg` | 0 |

> 🔗 این ابزار پایهٔ «Art-toy molds» (درخواست ۶ رأی) و «فرم‌های غیردوّار» است.

## استفادهٔ مشترک ابزارها از زیرساخت SolidVents

[SV-10/13/15/16/32/49/50](16-SOLIDVENTS-SPEC.md) زیرساخت بردار/مرز/fillet/ساخت را مشترک می‌کنند. کاتر arbitrary، چاپ slab، مهر و extruder از parser و canonical boundary مشترک استفاده کنند؛ خطای entity یا مسیر نامعتبر نباید به تقریب خاموش منجر شود.

پنل مشبک ابزار جدید مستقل است: layout + boundary + ligaments/edge clearance + open area + thickness + process compensation. hole ratio واقعی باید union clipped را حساب کند، نه مجموع دایره‌های همپوشان؛ روش تقریبی با error bound نمایش داده شود. kerf و حداقل feature به پروفایل دستگاه/ماده تعلق دارند، نه تضمین عمومی.

کارهای باز قبلی: کاتر دلخواه8.2، وکتور8.4، UI مسیر و اتصال واقعی دسته8.5، آزمون فیزیکی ریب8.6، extruder8.10، jigger8.14 و slab8.15. API sweep موجود صرفاً مسیر مقطع دایروی محدود است؛ union بدنه، اتصال۴mm و شواهد بارگذاری همچنان لازم است. نمونهٔ lattice یا STEP Shapes Only هیچ‌کدام این بندها را خودکار کامل نمی‌کنند.
