## 🧩 محصولی که می‌سازی

یک **نرم‌افزار طراحی پارامتریک دامنه‌محور برای سفال** به نام **Patturn Studio** (نام را می‌توانی تغییر دهی؛ برند و دارایی‌های بصری باید اصیل و تازه باشند).

> ### 🖥️ شکل تحویل: دسکتاپ ویندوز با اولویت آفلاین (الزامی)
> | پلتفرم | وضعیت | توضیح |
> |---------|:-----:|-------|
> | 🪟 **ویندوز ۱۰/۱۱ نصب‌شدنی** | 🔴 **اصلی** | نصب‌کنندهٔ `.exe`/`.msi`، اجرای **کاملاً آفلاین** بدون مرورگر و بدون اینترنت |
> | 🌐 نسخهٔ وب (مرورگر) | 🟡 اختیاری | همان SPA در صورت نیاز؛ هیچ ویژگی هسته‌ای وابسته به وب نباشد |
> | ☁️ سرویس ابری | 🔵 فاز بعد | همگام‌سازی/جامعه فقط در صورت اتصال؛ بدون بلوکه کردن کار آفلاین |
>
> **قواعد غیرقابل مذاکره:**
> 1. همهٔ محاسبات (هندسه، الگو، قالب، خروجی) **لوکال** اجرا میشوند — حتی با قطع کامل اینترنت.
> 2. پایگاه‌دادهٔ محلی (SQLite) **منبع حقیقت** است؛ سرور فقط آینه/همگام‌سازنده است.
> 3. خروجی‌ها مستقیم روی دیسک کاربر ذخیره میشوند (دیالوگ فایل ویندوز).
> 4. نصب، ارتقا و حذف باید تمیز و بدون نیاز به مهندس باشد.
> 5. جزئیات کامل: قانون **R-014** در `15-RULES.md` و بخش **۹** در `14-CHECKLIST.md`.

**وعدهٔ محصول در یک خط:**
> «هر سفالگر بدون هیچ دانش طراحی، با اسلایدر و نود، فرم چرخشی می‌سازد، الگوی بی‌درز روی آن می‌نشاند، قالب سیلیپ‌کستینگ چندتکه با کلید ثبت و مادرقالب تولید می‌کند و همه را با یک کلیک به‌صورت STL/SVG/DXF/PDF آمادهٔ ساخت می‌گیرد — با محاسبهٔ خودکار شیرینک، ظرفیت، و نسبت گچ/آب.»

**هستهٔ مفهومی که هرگز نباید شکسته شود — «قطعه‌های قابل ترکیب»:**

```
🟦 PATTERN  ←→  🟥 FORM  ←→  🟨 MOLD  ←→  📤 EXPORT
   (الگو)        (فرم)       (قالب)        (خروجی)
```

فرم، الگو و قالب **قطعه‌های مستقل و قابل ترکیب** هستند (مثل لگو). تغییر فرم باید الگو و قالب وابسته را به‌صورت خودکار بازمحاسبه کند. این یک **گراف وابستگی (DAG)** است، نه سه ابزار جدا.

### قواعد آهنین (Non-negotiables)
1. 📏 **واحد داخلی = میلی‌متر.** `number` خالص. تبدیل اینچ فقط در لایهٔ نمایش.
2. 🔁 **پروژه = JSON پارامترها، نه مش.** هندسه از پارامتر بازتولید می‌شود.
3. 🧊 **هر خروجی STL باید واترتایت و manifold باشد.** قبل از دانلود، اعتبارسنجی کن (euler characteristic، بدون لبهٔ باز، نرمال‌های یکدست) و در صورت نقص کاربر را باخبر کن.
4. 🎯 **قطعیت (Determinism).** همان پارامترها همیشه همان مش را بدهد. هیچ `Math.random()` بدون seed.
5. 🗂️ **نسخه‌بندی schema.** `schemaVersion` + migration. پروژه‌های قدیمی هرگز نشکنند.
6. 🚫 **بدون کد در رشته.** پارامترها فقط از نوع‌های شناخته‌شده (number, bool, enum, color, vector, curve) — هیچ `eval`.
7. 🧱 **مرز ماژول.** هر ابزار یک `ToolDefinition` مستقل در `packages/tools`؛ افزودن ابزار نباید هسته را تغییر دهد.
8. ♿ **دسترس‌پذیری.** هر کنترل با کیبورد، برچسب، و کنتراست AA.
9. 🌐 **RTL از روز اول.** نه بعداً.
10. 🧪 **تست هندسه.** برای هر فرمول، یک تست عددی با خطای مجاز ±۱٪.

## 📐 مشخصات عددی مرجع (این‌ها را دقیقاً پیاده کن و تست کن)

### ۱) محاسبهٔ ظرفیت فرم
ورودی نمونه: `w = 145 mm`, `h = 148 mm`, `wall = 4 mm`, `rim = 25 mm`, `fill = 80%`, `shrink = 12%`

```
حجم با تقسیم پروفیل داخلی به مخروط‌های ناقص:
  V = π/3 · Σ hᵢ · (rᵢ² + rᵢ·rᵢ₊₁ + rᵢ₊₁²)

ظرفیت (ml) = V_rim / 1000
حجم پرشده = انتگرال تا y_fill
y_fill = y_bottom + fill · (y_rim − y_bottom)

ابعاد خشک:
  d_dry = d_wet · (1 − shrink)
  V_dry = V_wet · (1 − shrink)³
```

**معیار پذیرش:** برای فرم مرجع، ظرفیت باید **≈ 1131 ml** و حجم پرشده در ۸۰٪ **≈ 958 ml** باشد (±۱٪). اگر نشد، هندسه یا ضخامت دیوار اشتباه است.

### ۲) محاسبهٔ گچ و آب قالب
```
ρ_plaster = 2.75 kg/L    ρ_water = 1.0 kg/L    r_w = 0.70 (آب:گچ)
V_mix = P/ρ_p + W/ρ_w = P·(1/2.75 + 0.70)
P(kg) = V_mix / (1/2.75 + 0.70)
W(kg) = 0.70 · P
```

**معیار پذیرش:** `V_mix = 1.84 L` → **P ≈ 1.72 kg** و **W ≈ 1.20 kg** (±۲٪).

### ۳) کلید ثبت
```
کلید مخروطی:  r_top = r_base + h · tan(taper)     taper پیش‌فرض ۴°
نیم‌کره:      کلاهک با شعاع R و ارتفاع عارضه h
تلورانس:      gap ∈ [0.10, 0.50] mm  (پیش‌فرض 0.20)
```

### ۴) شرایط قالب drop-out تک‌تکه
```
قالب تک‌تکه مجاز است اگر برای همهٔ y در جهت بیرون‌آمدن:  d r(y)/dy ≥ 0
(یعنی فرم از پایین به بالا هرگز باریک‌تر نشود)
اگر نقض شد → تقسیم خودکار به n قطعه با صفحهٔ جداایش
```

### ۵) مش شکم‌دار (Belly) — فرم نمونهٔ سایت
`Rim 32 · Belly 64 · Foot 46 · Height 78` (قطرها به mm) — فرم کنترل‌شده با ۴ نود اصلی + دوترکیب Bezier.

type PatternNode = {

};
type MoldNode = {
  mode: 'single'|'multi';
  parts: number;
